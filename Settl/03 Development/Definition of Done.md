# Definition of Done

A feature is done only when:

- [ ] Code is implemented.
- [ ] Relevant unit tests exist.
- [ ] Integration behavior is tested where applicable.
- [ ] Error handling exists.
- [ ] Audit behavior is defined if financial state changes.
- [ ] Documentation is updated.
- [ ] The feature works locally.
- [ ] Existing tests still pass.

## MVP is done when

- [ ] Failed payment can become a recovery case.
- [ ] AI/ML analysis runs.
- [ ] Policy can ALLOW / STOP / ESCALATE.
- [ ] Real Test Mode Payment Link can be created.
- [ ] Successful payment produces verified webhook.
- [ ] Case becomes RECOVERED.
- [ ] Recovered amount appears in dashboard.
- [ ] Audit trail exists.
- [ ] Blocked case creates no financial action.
- [ ] Locked evaluation runs.
- [ ] Synthetic and real results are clearly separated.
